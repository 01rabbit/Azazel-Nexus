# HG-01 — installation leaves operational units masked

Owner: [#115](https://github.com/01rabbit/Azazel-Nexus/issues/115) pilot,
[#4](https://github.com/01rabbit/Azazel-Nexus/issues/4) campaign.
Status: **not run; hardware-unverified**.

Use the [campaign prerequisites and stop conditions](../hil-campaign.md) and
[evidence lifecycle](../hil-evidence-records.md). This tests the installed
image's systemd enforcement and install-time network behaviour. It does not
prove later activation correctness, observation-role silence, or another
systemd/image/hardware tuple.

1. Start from the approved clean target image with no activation grant. Establish
   local console recovery and independent capture on every attached link before
   installation; account for wireless interfaces through approved isolation and
   observation. If coverage is unavailable, packet silence is unverified.
2. Record the exact installer/image/commit and systemd version. Install via
   `packaging/install.sh` using its documented procedure. Retain exit status and
   classified findings; do not change presets to obtain a pass.
3. Use the `az-hil-capture hg-01` read-only acquisition command (see
   [tools](../hil-evidence-records.md#tools-and-trust)) for the unit list,
   installed state, active state and systemd version. Cross-check the complete
   governed-unit set against the installed package, not a remembered list.
   Read `systemctl list-unit-files 'azazel-*'` and `systemctl is-active` for
   each governed unit where needed; a nonzero `is-active` result alone is not
   proof of a mask. Inspect enabled/masked state as well. The activation
   controller is the declared exception; operational units must remain masked,
   disabled from activation-by-default, and inactive.
4. Reboot without issuing activation and repeat the checks. In a separately
   approved preset exercise, apply the image's normal preset policy and recheck
   that no operational unit is enabled or started. Preserve both observations.
5. Correlate the independent capture interval with installation and reboot.
   Identify any operational network traffic and its origin; background traffic
   must not be silently attributed to the DUT or excluded without evidence.
   Capture loss or incomplete link coverage makes the silence claim incomplete.
6. Retain per-unit observations, acquisition method, systemd/image context,
   capture-health results and the claimed outcome in the HG-01 record. Sanitise,
   attest and validate with the `azazel_nexus.hil_records.validate_record` (`azazel-nexus/hil-gate/v1`).

An unexpectedly active or unmasked unit fails the exercise. Stop dependent
activation; from the recovery console stop/disable and re-mask the affected
operational units under authorised maintenance, verify inactive/masked state
and independently verify exposure has ceased. Keep the failure and restoration
observations; if restoration cannot be verified, keep the DUT isolated. Never
count remediation as the original installation passing.
