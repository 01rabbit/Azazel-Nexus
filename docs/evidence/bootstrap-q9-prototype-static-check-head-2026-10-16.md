### 4.4 Observations from the trace (all non-blocking)
- T1 In the exception branch `run` does not call `_release_deadline_guard` when `_finish_transaction` raises (`recovery_required`, containment failure, unrecorded close); the kernel timer stays armed and the controller dies at the original absolute deadline. Same as 81d4530.
- T2 READY=1 starts the 30 s watchdog. The first WATCHDOG=1 is now sent right after the READY step (bs:897). The READY step can last up to 25 s plus the closing `check_ready()` (bs:892), so the worst case READY to first watchdog is about 25 s + one full check, margin about 3 s at the measured 1.7 s per check. ## 6. Findings

Blocking: none. Nothing in the switched path sends a forbidden member, operates on an arbitrary unit, or writes outside the permitted locations.

Non-blocking:
- O1 Retirement is a new write path (J7).
